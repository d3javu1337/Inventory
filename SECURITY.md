# Безопасность локального MVP

Целевая среда — один доверенный компьютер и его Docker/Android-эмулятор.
Это не конфигурация для Интернета или недоверенной локальной сети и не защита
от другого пользователя, уже имеющего доступ к этому компьютеру/Docker.

## Границы доступа

- API: `127.0.0.1:5147`, web: `127.0.0.1:5173`; demo: loopback 15147/15173.
- PostgreSQL и Redis не имеют host-портов. Metro через `npm start` слушает
  `127.0.0.1`; не передавайте `--host 0.0.0.0` и не открывайте его туннелем.
- Анонимная HR-интеграция доступна только через прямой локальный API/доверенную
  Docker-сеть. Nginx запрещает `/internal` и все вложенные маршруты.
- Первый пароль администратора нужно задать сразу после первого запуска.
  Не делитесь доступом к компьютеру до завершения первоначальной настройки.
- Development JWT-ключ и пароль локальной БД известны из исходников. HTTP
  допустим только в описанной среде. Не меняйте привязки на LAN/публичный адрес.

## При смене среды

Вне Development API отказывается запускаться с дефолтным JWT-ключом/паролем БД
или неточным HTTPS CORS. Нужны отдельные случайные секреты, TLS и конкретные
доверенные IP reverse proxy. Refresh cookie в этом режиме всегда Secure.
Публичный HR endpoint потребует отдельной аутентификации/сетевой защиты.
Технический release APK подписан debug-ключом и не предназначен для распространения.
Не считайте переключение одной переменной готовым production-развертыванием.

## Данные и секреты

JWT проверяет актуальную учетную запись в БД; cache-aside хранит только
отображаемые DTO справочников/dashboard, не результаты авторизации.
Пароли/refresh tokens не должны попадать в логи, Git или скриншоты.
Live-браузерные тесты получают пароль администратора только из окружения,
используют отдельные сеансы, отключают trace/video/screenshots и удаляют
DOM failure-контексты (`preserveOutput: never`): значение password input может
попасть в текстовый snapshot даже без скриншота. Обычные проверки не меняют
рабочие бизнес-данные; тесты записи требуют явного UUID синтетического клона.
Мобильный web-адаптер на 5174 предназначен только для локальной эмуляции:
refresh token хранится в browser localStorage, не в Android Keystore. Не
публикуйте этот Vite-сервер в LAN/Интернет и не используйте адаптер как
production-клиент. Нативное приложение продолжает использовать Keystore.
Файлы `.env`, ключи и backup исключены из Git. Резервные копии содержат
персональные данные и хеши: храните их с ограниченным доступом.
Восстановление рабочей БД выполняйте только после новой копии и ее проверки.
